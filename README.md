# IFRS Quest

Un juego web sencillo para enseñar las Normas Internacionales de Información Financiera (IFRS) a través de dinámicas de gamificación. El objetivo es que los equipos financieros practiquen conceptos clave mediante misiones, cartas de escenario y logros.

## Características

- **Misiones temáticas**: Fundamentos, reconocimiento y medición, y revelaciones IFRS.
- **Cartas de escenarios** con decisiones múltiples y retroalimentación inmediata basada en la norma aplicable.
- **Sistema de XP y niveles** para incentivar el progreso continuo.
- **Logros desbloqueables** que celebran hitos como rachas de respuestas correctas o completar cartas.
- **Recursos oficiales IFRS** enlazados para profundizar en cada tema.

## Cómo usarlo

1. Abre `game/index.html` en tu navegador.
2. Selecciona una misión y analiza la carta de escenario.
3. Elige la mejor respuesta, revisa la explicación y continúa con la siguiente carta.
4. Repite hasta dominar cada norma y desbloquear todos los logros.

## Personalización

- Agrega nuevas misiones o escenarios editando `game/script.js`.
- Ajusta la estética del juego modificando `game/styles.css`.
- Complementa el contenido con casos propios de tu organización para reforzar el aprendizaje contextual.
